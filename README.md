# Abhinav_Ksheeraj_Active_Suspension_Control
Active Suspension Control System using PID/PD Controller in MATLAB/Simulink. Designed for a 1-Day Control Craft Hackathon. The system minimizes vehicle body displacement due to road disturbances by controlling the plant G(s) = 1/(s²+3s+2). Includes uncontrolled vs controlled response comparison, settling time analysis, and damping evaluation.
